## 2. 前置合规风险检查

### 2.1 类目判断与风险等级

- **类目判断**：草本植物饮料 / 普通饮料。
- **整体风险等级**：中等。
- **主要风险来源**：甘草、百合、枇杷容易引发中药功效联想；“0 脂、轻负担、解腻、熬夜”等词容易被过度延展为健康功效或身体改善承诺。
- **处理原则**：只讲“口感、风味、场景、规格、饮用方式”；涉及营养、配料、资质、数据、口碑、价格、活动权益的信息，必须基于真实资料。

### 2.2 可用表达

- 入口清甜、后味回甘、清爽不厚重、不苦、不齁甜。
- 轻草本风味、冰镇更好喝、夏天来一罐、日常饮用。
- 火锅烧烤搭配、夜宵聚餐搭配、办公室常备、冰箱囤货、追剧小食搭配。
- 310mL/罐、12 罐/箱、整箱更方便。

### 2.3 慎用表达

- **0 脂**：必须有营养成分表支持；无依据时替换为“清爽轻负担”。
- **轻负担**：可作为饮用感受，不得写成“0 负担、完全无负担”。
- **解腻**：建议使用“口感不腻”“重口餐食搭配更清爽”。
- **草本**：只表达风味、气味和视觉记忆，不解释具体身体功效。
- **熬夜**：只做追剧/夜宵桌面场景，不承诺提神、恢复、护肝或改善状态。

### 2.4 禁用表达

- 治疗嗓子、护嗓、润肺、清肺、止咳、化痰、消炎。
- 降火、清热解毒、改善上火、排毒、祛湿、疾病预防、疾病治疗。
- 药效、疗效、处方、医生推荐、专家背书、替代药品。
- 0 负担、完全无负担、绝对安全、100% 有效、全网第一、销量第一、最低价。

### 2.5 需补充依据表达

- “0 脂”：需营养成分表。
- “甘草、百合、枇杷”：需真实配料表或包装标注。
- “生产许可、执行标准、检测报告”：需真实包装或资质文件。
- “好评、复购、达人推荐、销量”：需后台数据、授权素材或真实评价证据。

- **设计执行说明**：AI 图不能生成证书或检测报告正文；设计师需放入真实拍摄素材；未补齐前本屏只作为模板，不可上线；不要出现“权威认证”“专家推荐”等无依据词。
- **合规风险**：高风险屏，所有背书都必须可验证；不得伪造生产许可、执行标准、检测报告、销量和好评。

### 详情页 12：FAQ 与转化收口｜你关心的口感和场景，这里说清楚

- **主标题**：你关心的口感和场景，这里说清楚
- **副标题**：清爽好喝，整箱囤更方便
- **正文文案**：用 FAQ 解除“会不会苦、会不会太甜、什么时候喝、能不能冰镇、整箱会不会喝不完”等下单前顾虑，并用多场景 + 整箱囤货做最终转化收口。
- **视觉方向**：FAQ 卡片 + 产品整箱堆头 + 四个场景小卡，既回答问题又推动加购。
- **构图说明**：上半屏 4-5 个问答卡片；下半屏整箱和多罐堆头，周围放“聚餐 / 夜宵 / 办公室 / 冰箱常备”小卡；底部 CTA 使用“囤一箱清爽好喝”。
- **AI 生图提示词**：

```text
移动端详情页FAQ和转化收口模块，浅米白背景，上半部分多个圆角问答卡片，问题围绕会不会苦、会不会太甜、适合什么时候喝、可以冰镇吗；下半部分茶活力12罐整箱和多罐产品堆头，包装清晰，周围四个场景小卡：聚餐、夜宵、办公室、冰箱常备；底部CTA区域，囤一箱清爽好喝；清爽抖音电商成交风格；负面提示词：医疗问诊、治疗疾病问答、最低价、销量第一、虚假限时、错误文字、包装变形
```

- **设计执行说明**：FAQ 每条回答不超过 2 行；示例：Q“会不会苦？”A“主打入口清甜、后味回甘，口感更清爽。”；Q“什么时候喝？”A“火锅烧烤、夜宵聚餐、办公室、冰箱常备都适合。”；CTA 不写“必买、最低价”，如有真实活动再替换为平台权益。
- **合规风险**：FAQ 不回答疾病、嗓子、清肺、降火相关问题；CTA 避免绝对化和虚假限时；场景适合仅指饮用场景，不指特殊人群或疾病。

## 5. 统一设计执行说明

### 5.1 尺寸与版式

- **商品卡主图**：优先 1:1，兼容 4:5 广告裁切；产品主体占比 45%-70%；主标题需在抖音商品卡缩略图中可读。
- **详情页长图**：建议 750px 宽，每屏高度 900-1200px；每屏只解决一个用户问题，避免信息堆叠。
- **文字层级**：主标题最大，副标题第二，说明文字第三；脚注和依据说明使用小字号但必须可读。
- **移动端可读性**：标题控制在 12-18 字，标签控制在 3-6 字，小字不超过 2 行。

### 5.2 视觉语言

- **主色**：米白、浅绿、淡黄，形成“夏天、清爽、轻草本”的货架识别。
- **辅助色**：冰蓝用于冰镇感，暖橙用于餐桌场景，避免大面积深棕和药感色。
- **常用元素**：冰块、水珠、透明杯、淡黄色饮品、浅绿叶影、整箱陈列、办公室工位、冰箱、夜宵桌。
- **避免元素**：医院、药房、医生、白大褂、药片、药材铺、深棕药汤、滋补讲座、功效证书伪造图。

### 5.3 AI 生图与设计协作

1. AI 生图只生成底图、氛围、场景和静物结构，不直接生成最终包装文字、资质编号和营养数据。
2. 设计师必须用真实罐身、真实箱体、真实背标替换 AI 生成包装。
3. 所有中文主文案、规格、价格、活动权益由设计师后期排版，避免 AI 乱码。
4. 原料元素必须与真实配料表一致；未确认前只用抽象浅绿叶影和清爽饮品元素。
5. 运营审核时按合规检查表逐项核对，尤其是“0 脂、草本原料、资质背书、价格活动”。

## 6. 最终合规检查表

| 检查项 | 当前建议 | 风险等级 | 处理方式 |
|---|---|---:|---|
| 类目表达 | 草本植物饮料 / 普通饮料 | 低 | 可用，不写保健食品、功能饮料或药品 |
| 口感表达 | 入口清甜、后味回甘、清爽、不苦、不齁甜 | 低 | 可作为主视觉核心 |
| 夏日表达 | 冰镇更好喝、夏天来一罐 | 低 | 可用，只表达饮用体验 |
| 场景表达 | 火锅烧烤、夜宵、办公室、冰箱常备 | 低 | 可用，只表达饮用场景 |
| “轻负担” | 清爽轻负担、想喝饮料也想轻一点 | 中 | 可慎用，不得写 0 负担、完全无负担 |
| “0 脂” | 0 脂轻负担 | 中 | 必须有营养成分表支持；无依据改为“清爽轻负担” |
| 草本配料 | 甘草、百合、枇杷 | 中 | 需真实配料表支持；只说风味，不说功效 |
| “解腻” | 解腻感 | 中 | 主文案建议不用；替换为“口感不腻”“搭配更清爽” |
| 熬夜场景 | 追剧夜宵、加班桌面 | 中 | 只做场景，不写提神、恢复、护肝 |
| 价格信息 | 50 元左右/箱 | 中 | 正式上线按真实售价替换，禁止最低价 |
| 活动权益 | 优惠、赠品、限时 | 高 | 未提供不得展示，不得虚构 |
| 资质背书 | 生产许可、执行标准、检测报告 | 高 | 未提供不得展示，不得伪造 |
| 医疗功效 | 降火、清肺、止咳、护嗓、润肺、治疗嗓子 | 高 | 全部禁用 |
| 绝对化表达 | 第一、最强、100% 有效、全网最低、销量第一 | 高 | 全部禁用 |
| 竞品对比 | 比凉茶更健康、比某饮料更有效 | 高 | 不做无依据对比，不贬低竞品 |
| AI 图包装 | AI 生成罐身、背标、资质 | 中 | 仅用于方向，正式稿需真实素材替换 |
