## 2. 产品定位分析

### 2.1 一句话定位

**一款适合夏天冰镇、餐食搭配和办公室常备的清爽草本风味饮料，主打入口清甜、后味回甘、好喝不苦、轻负担的日常饮用体验。**

### 2.2 抖音商品卡成交定位

- **用户为什么会点**：用户刷到“不是苦凉茶 / 不齁甜 / 夏天冰镇更清爽”时，能快速识别这是区别于厚重凉茶和高甜饮料的轻草本饮料。
- **用户为什么会信**：通过罐装实物、整箱规格、真实配料表/营养成分表占位、清爽场景图，降低“草本饮料是不是像药、是不是苦”的顾虑。

### 2.3 核心人群

1. **年轻上班族 / 学生党**：想喝有味道的饮料，但担心太甜、太腻；适合办公室、宿舍、冰箱常备。
2. **火锅烧烤 / 夜宵聚餐人群**：需要一罐冰镇、口感清爽的餐食搭配饮料。
3. **轻草本尝鲜人群**：对甘草、百合、枇杷等草本风味有兴趣，但不想喝厚重苦凉茶。
4. **家庭囤货人群**：希望购买一箱日常可喝、场景不受限、老人小孩以外普通家庭成员也容易接受的饮品；如涉及儿童、孕妇、特殊人群需额外合规审核。

## 3. 前置合规风险检查

### 3.1 风险等级

- **类目判断**：草本植物饮料 / 普通饮料。
- **整体风险等级**：中等。风险主要来自“甘草、百合、枇杷”容易被误读为中药功效，以及“0 脂、轻负担、解腻、熬夜”等表达容易越界。
- **方案处理原则**：只讲口感、风味、场景、规格、饮用方式；涉及数据、资质、检测、0 脂、配料必须以后续真实资料为准。

### 3.2 可用表达

- 清爽、入口清甜、后味回甘、不苦、不齁甜、草本风味、轻草本、冰镇更好喝、夏天来一罐、日常饮用。
- 火锅烧烤搭配、夜宵聚餐搭配、办公室常备、冰箱囤货、追剧小食搭配。
- 310mL/罐、12 罐/箱、约 50 元/箱（正式投放需按页面真实价格核验）。

### 3.3 慎用表达

- **0 脂**：需营养成分表支持；无依据时改为“清爽轻负担”。
- **轻负担**：可作为饮用感受表达，不得写成“0 负担、完全无负担”。
- **解腻**：建议改为“口感不腻”“重口餐食搭配更清爽”。
- **草本**：仅做风味与视觉元素，不解释成具体身体功效。
- **熬夜**：只能作为追剧/夜宵桌面场景，不承诺提神、修复、护肝、恢复状态。

### 3.4 禁用表达

- 治疗嗓子、护嗓、润肺、清肺、止咳、化痰、消炎。
- 降火、清热解毒、排毒、祛湿、改善上火、改善疾病。
- 药效、疗效、处方、医生推荐、专家背书。
- 0 负担、完全无负担、100% 有效、全网第一、最低价、销量第一。

### 3.5 需补充依据

- “0 脂”：需营养成分表。
- “甘草、百合、枇杷”：需真实配料表。
- “生产许可、执行标准、检测报告”：需真实包装或资质文件。
- “销量、好评、复购、达人推荐”：需后台数据、授权素材或真实评价证据。

- **视觉方向**：真实包装背标、营养成分表、生产许可、执行标准的清晰截图/照片信息墙；没有真实素材时用“待补充资料”占位。

```text
移动端详情页信任信息模块，干净白底信息卡片布局，四个卡片占位：配料表、营养成分表、生产许可、执行标准或检测资料，旁边放茶活力草本饮单罐和包装背面展示占位，整体真实可信的电商详情页风格，米白浅绿点缀；文字区域清晰，提示以真实包装和资质文件为准；禁止伪造认证、专家背书、医生推荐、虚假检测报告、功效证书
```

- **设计执行说明**：这是合规审核重点屏，必须用真实拍摄或官方资质文件替换占位；如确认营养成分表中脂肪为 0，才可在前文使用“0 脂”；不要放任何无授权达人、专家、机构背书。

## 7. 统一设计执行说明

### 7.1 尺寸与版式

- **商品卡主图**：优先 1:1，同时预留 4:5 广告图裁切版本；产品主体占比 45%-70%，确保抖音信息流快速识别。
- **详情页**：建议 750px 宽长图，每屏高度 900-1200px；每屏只讲一个核心问题，标题、画面、说明三层即可。
- **移动端字级**：主标题要在手机端 2-3 秒读完，避免超过 16-18 字；标签控制 3-6 字；小字用于脚注和依据说明。

### 7.2 视觉语言

- **主色**：米白、浅绿、淡黄，形成清爽夏天和轻草本识别。
- **辅助元素**：冰块、水珠、透明杯、淡黄色饮品、浅绿叶影、整箱陈列、办公室/夜宵/冰箱场景。
- **避免风格**：深棕药汤、中药铺、药材堆、医院蓝白、医生、药片、养生讲座、传统滋补海报。

### 7.3 运营审核要点

1. 上线前核对包装、规格、价格、促销是否与商品页一致。
2. 所有“0 脂”必须有营养成分表截图或背标支持。
3. 甘草、百合、枇杷等具体配料必须以真实配料表为准。
4. 删除所有降火、清肺、护嗓、止咳、清热解毒、排毒等高风险词。
5. AI 生图只能生成场景和氛围，最终包装、背标、资质必须使用真实素材替换。
