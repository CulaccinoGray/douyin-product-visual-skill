# 示例产品资料：茶活力即饮茶

> 本文件为虚构示例，仅用于演示资料填写结构，不代表真实商品、资质或功效。

## 1. 基础信息

- 产品名称：茶活力即饮茶
- 品牌名称：茶活力
- 商品类目：饮料 / 即饮茶
- 规格/容量/包装：500ml 瓶装，12 瓶整箱
- 售卖平台：抖音电商
- 目标价格带：中端日常囤货价格带
- 主要销售场景：商品卡 / 信息流广告 / 直播间 / 店铺详情页

## 2. 目标用户

- 核心人群：上班族、学生、轻运动人群
- 年龄/性别/地域特征：18-35 岁，男女均可，一二线及新一线城市为主
- 消费动机：想买一款清爽、低负担、适合日常饮用的茶饮
- 使用场景：通勤、办公室、学习、轻运动后、聚餐搭配
- 购买顾虑：甜腻、热量、口感是否寡淡、整箱是否划算

## 3. 产品卖点

- 核心卖点 1：茶香清爽，适合日常饮用
- 核心卖点 2：整箱装，适合办公室或家庭囤货
- 核心卖点 3：包装简洁，冷藏后饮用体验更佳
- 可证明依据：配料表、营养成分表、包装实拍、用户口感反馈
- 不可使用或需谨慎表达的卖点：减肥、燃脂、降糖、治疗、排毒、改善疾病等功效表达
