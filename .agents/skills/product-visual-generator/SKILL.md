# product-visual-generator

## 1. Skill 定位

`product-visual-generator` 用于在用户提供产品资料后，生成一套可直接交给抖音电商运营、设计师、内容团队和 AI 生图工具执行的产品视觉方案。

核心产出必须围绕抖音电商成交链路展开：**谁会买、为什么会点、为什么会信、为什么现在买、如何减少顾虑并促成下单**。视觉审美必须服务点击率、理解效率、信任建立和购买转化，不要只输出品牌广告感、概念大片感或空泛高级感。

适用输出包括：商品卡主图、信息流广告图、直播间入口图/贴片视觉、短视频封面、详情页长图结构、AI 生图提示词、设计执行说明、合规风险检查、最终 Markdown 交付文件。

## 2. 交付原则与不可逾越红线

### 2.1 交付原则

- 默认使用**中文**输出，除非用户明确要求其他语言。
- 结果必须结构化，便于复制给设计、内容、运营和 AI 生图团队。
- 所有建议都必须解释其转化作用，例如吸引点击、放大痛点、强化卖点、建立信任、呈现场景、降低决策成本或推动立即购买。
- 每条视觉建议都要落到可执行细节（主体比例、文案层级、卖点位置、背景场景、色彩、光影、素材、移动端可读性），不要停留在“高级、干净、大气、品牌感”等抽象风格词。
- 只给概念方向而不给文案、构图、素材和执行说明，视为不合格。

### 2.2 不可逾越红线（任何输出前先自查）

- 不要虚构资质、检测报告、销量、专利、认证、达人背书、专家背书或用户评价。
- 不要输出医疗功效、疾病预防、疾病治疗、药品化表达，也不要把普通食品/饮料/营养品写成药品或治疗方案。
- 不要使用绝对化用语（“第一”“最强”“顶级”“永久”“100%有效”“零风险”等无依据表达）。
- 不要做无依据竞品对比或贬低竞品。
- 食品、饮料、营养品、保健食品等类目必须**先做合规风险检查，再**输出卖点、文案、画面和提示词。
- 没有产品资料时，不要直接生成完整方案；先列出关键信息缺口，并说明可在何种安全假设下推进。
- 用户只要求维护 Skill、规则或模板时，不要虚构具体产品案例。

> 红线细则与高风险词替代表达见 `references/compliance-rules.md`，不在本文件展开。

## 3. 输入要求

### 3.1 用户应尽量提供的信息

生成方案前，优先读取用户提供的产品资料文件或文本（可参考 `product_inputs/product-template.md` 的字段、`product_inputs/example-tea-huoli.md` 的填写示例），并提取：

```markdown
- 产品名称：
- 产品类目：普通食品 / 饮料 / 营养品 / 美妆 / 个护 / 家清 / 服饰 / 数码 / 其他
- 品牌名称：
- 规格与包装：容量、数量、组合装、口味、材质、包装形式
- 价格带与促销信息：日常价、活动价、赠品、满减、直播间福利（必须基于真实资料）
- 目标用户：年龄、性别、城市级别、消费场景、购买动机、使用频次
- 核心卖点：原料、配方、工艺、功能、口感、便携、颜值、服务、性价比等
- 证据资料：检测报告、资质、认证、专利、营养成分表、配料表、生产信息、真实评价
- 竞品或替代选择：用户正在比较什么，不能无依据贬低竞品
- 使用场景：办公室、早餐、健身、露营、家庭囤货、送礼、直播间等
- 视觉素材：产品实拍、包装图、品牌 Logo、原料图、场景图、模特图、详情页旧稿
- 投放场景：商品卡 / 信息流广告 / 直播间 / 短视频封面 / 详情页
- 尺寸要求：如 1:1、3:4、4:5、16:9、750px 宽详情页等
- 禁用信息：不能出现的词、竞品、人物、场景、色彩或平台限制
```

### 3.2 资料不足时的处理

如资料不足，不要编造事实。应先输出：

1. **影响转化判断的信息缺口**：例如目标用户、价格带、主卖点、使用场景、竞品环境。
2. **影响合规判断的信息缺口**：例如营养成分表、配料表、检测报告、资质证明、功能宣称依据。
3. **可继续推进的安全假设**：只使用通用、低风险、可撤换的表达，例如口感、场景、规格、便携、包装和真实可见信息。
4. **需要用户补充的资料清单**：按优先级列出必须补充与可选补充。

## 4. 参考资料加载策略（单一信息源）

**所有硬性规范——主图张数与递进分工、详情页屏数与结构、标题字数、产品主体占比、信息层级、合规红线细则、AI 生图提示词字段与风格模板——均以 `references/` 为唯一来源，本 SKILL 文件不重复定义，避免出现互相矛盾的数字。** 根据任务按需加载：

- 做主图、商品卡、广告图、直播间入口图、短视频封面时，读取 `references/main-image-framework.md`。
- 做详情页、长图、卖点解释页、决策链路设计时，读取 `references/detail-page-framework.md`。
- 涉及食品、饮料、营养品、保健食品、健康功效、成分功效、低糖/低脂/低卡、检测报告、认证资质时，读取 `references/compliance-rules.md`。
- 需要统一视觉语言、移动端可读性、版式规范、AI 生图提示词时，读取 `references/visual-style-rules.md`。

## 5. 工作流程

### Step 1：解析产品资料

- 提取产品名称、类目、规格、价格带、目标用户、使用场景、真实卖点和视觉素材。
- 区分“用户明确提供的信息”和“需要补充依据的信息”。
- 判断该商品更适合用哪类转化抓手：痛点型、场景型、性价比型、成分/工艺型、颜值型、信任背书型、礼赠型或直播福利型。

### Step 2：合规风险检查

必须在方案前段输出合规检查，尤其是食品、饮料、营养品、保健食品类目。判断维度（类目与风险等级、医疗化/绝对化表达、需依据的营养宣称、需证明的资质数据等）与高风险词替代表达，统一按 `references/compliance-rules.md` 执行，并将表达分为：**可用表达、慎用表达、禁用表达、需补充依据表达、稳妥替代表达**。

### Step 3：产品定位与成交策略

输出产品定位必须回答：

- 产品一句话定位：它是什么，解决什么消费需求。
- 目标用户：谁最可能买，为什么买。
- 核心购买理由：用户为什么愿意停留、点击、咨询或下单。
- 信任来源：哪些证据能降低顾虑。
- 场景切入：在哪些抖音电商场景中最容易触发购买。
- 转化路径：主图负责点击，详情页负责解释与信任，直播间视觉负责福利与即时决策。

### Step 4：卖点排序

卖点排序不能只按品牌想说什么排序，应按用户决策优先级排序：

1. **点击钩子**：首屏最容易让用户停下来的需求、痛点或利益。
2. **核心利益点**：最能解释“为什么买它”的卖点。
3. **可信证据**：资质、配料、工艺、规格、真实数据或可验证信息。
4. **场景代入**：用户能立即想象自己何时使用。
5. **购买推动**：组合装、赠品、活动、囤货、售后等真实下单理由。

每个卖点都应标注：用户需求/顾虑、可用文案方向、证明材料、适合出现的位置（主图 / 详情页 / 直播间 / 广告图）、合规风险。

### Step 5：生成主图方案

读取 `references/main-image-framework.md`，按其**递进式分工**（第 1 张抓点击 → 第 2 张打痛点 → 第 3 张讲产品理由 → 第 4 张讲使用体验 → 第 5 张建信任 → 第 6 张场景强化 → 第 7 张广告/直播间转化图）输出 5-7 张方案，每张图独立承担一个转化目标，避免重复堆同一卖点。每张图的必填字段、标题字数、主体占比等以该参考文件为准；可结合投放场景裁剪张数。

### Step 6：生成详情页方案

读取 `references/detail-page-framework.md`，按其**购买决策递进结构**（前 3 屏解决“为什么买/为什么继续看” → 中段建立卖点、差异与信任 → 后段解决规格、使用、顾虑与下单）输出方案，默认 14 屏，可在 10-15 屏区间按品类增减。每屏的必填字段以该参考文件“每屏必填字段模板”为准。

### Step 7：生成 AI 生图提示词

按 `references/visual-style-rules.md` 第三节的字段与风格模板，为每张主图和每类关键详情页画面输出可执行提示词。要点：只描述画面（主体/场景/构图/光线/质感/色彩/留白），不编造产品事实；明确预留中文文案区，不要求模型生成大段中文小字；每条都附负面提示词（禁止虚假认证、夸张功效、错误文字、竞品 Logo、医疗暗示等）。

## 6. 输出模式

先确认用户需要的范围；不确定时默认 **full** 并在开头说明，合规检查在任何模式下都必做。

- **full（默认）**：完整方案，含第 7 节全部模块。
- **quick**：用户只要主图、只要详情页或只要提示词时，只输出对应模块 + 合规检查，不必强行铺满全套。

## 8. 交付前质量自查

输出前逐项自查，不通过则修正后再交付。详细标准见对应 reference。

- **转化**：是否说清定位、人群和购买动机？卖点是否按用户决策优先级排序？主图能否在移动端 1 秒看懂品类、主体和核心利益点？详情页是否按“需求确认 → 场景代入 → 卖点解释 → 证据支撑 → 顾虑解除 → 转化收口”展开？每个画面是否说明了转化作用？
- **执行**：每张主图/每屏详情页是否都包含文案、构图、素材、设计执行说明和合规注意？AI 生图提示词是否具体到主体、场景、构图、光线、色彩、留白和负面提示词？设计师能否直接拆成作图任务、运营能否直接审核、内容团队能否直接取用文案？方案是否适配抖音商品卡、直播间、广告图和移动端详情页落地？
- **合规**：是否先做合规检查再出卖点和画面？是否守住第 2.2 节全部红线？需依据的表达是否标注“需补充依据”？食品/饮料/营养品是否改用更稳妥的场景与产品特征表达？
- **结构**：Markdown 层级清晰、表格字段完整、信息落到可执行细节。
