# 抖音电商产品视觉生成 Skill

## 工作目标

根据用户提供的产品资料文件，输出一套可执行的抖音电商产品视觉方案。始终优先服务成交转化，而不是只追求画面美观。

## 默认输出规则

- 默认使用中文。
- 先读取产品资料，再判断类目、目标人群、价格带、核心卖点和合规风险。
- 用户只要求搭建结构或规则时，不生成具体产品内容。
- 如资料缺失，先列出影响转化判断的关键信息缺口，再给出可继续推进的假设范围。
- 食品、饮料、营养品、保健食品等类目必须先加载 `references/compliance-rules.md` 并进行合规自查。

## 推荐工作流

1. **解析资料**：读取产品名称、类目、规格、目标用户、卖点、价格带、使用场景和视觉资产。
2. **合规审查**：识别是否涉及食品、饮料、营养品、保健食品、功效宣称、数据背书或竞品对比。
3. **转化策略**：明确用户为什么会点、为什么会信、为什么现在买。
4. **主图规划**：按 `references/main-image-framework.md` 输出商品卡主图、广告图、直播间入口图方向。
5. **详情页规划**：按 `references/detail-page-framework.md` 输出页面模块、信息顺序和视觉节奏。
6. **风格约束**：按 `references/visual-style-rules.md` 统一色彩、版式、字体、素材和移动端可读性。
7. **交付整理**：输出设计师可执行清单、AI 生图提示词方向和待补充素材清单。

## 参考资料加载策略

- 做主图、广告图、商品卡、直播间入口图时，读取 `references/main-image-framework.md`。
- 做详情页、长图、卖点解释页时，读取 `references/detail-page-framework.md`。
- 涉及食品、饮料、营养品、保健食品、健康功效、成分功效、检测报告时，读取 `references/compliance-rules.md`。
- 需要统一视觉语言、风格、移动端可读性、提示词方向时，读取 `references/visual-style-rules.md`。

## 建议输出结构

```markdown
# 产品视觉方案：{产品名称}

## 1. 输入资料摘要
## 2. 合规风险与可用表达
## 3. 转化策略
## 4. 主图/广告图/直播间视觉方案
## 5. 详情页视觉方案
## 6. AI 生图提示词方向
## 7. 设计执行清单
## 8. 待补充资料
```

## 禁止事项

- 不要虚构资质、检测报告、专利、认证、销量或用户评价。
- 不要输出医疗化、治疗化、绝对化、夸大化表达。
- 不要把食品、饮料、普通营养品写成药品或保健治疗方案。
- 不要生成无法落地的抽象审美描述；必须转化为画面层级、文案位置、素材和执行要求。
