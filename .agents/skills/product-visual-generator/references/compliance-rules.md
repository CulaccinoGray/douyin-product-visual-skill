# 合规规则：食品、饮料、营养品电商视觉文案

> 本文件用于抖音电商商品卡主图、广告图、直播间入口图、详情页和 AI 生图提示词的合规自查。规则重点适配食品、饮料、营养品、普通食品、草本饮和滋补类产品。本文不替代律师、平台规则、广告审查机关或监管部门意见；涉及高风险宣称、保健食品、特殊医学用途配方食品、功能声称、检测认证和疗效暗示时，必须要求用户提供真实资质并进行专业审核。

## 1. 核心原则

1. **先判断类目，再写文案**：普通食品、饮料、营养补充类产品不得被包装成药品、医疗器械或保健食品；保健食品也不得超出注册/备案内容表达。
2. **先看证据，再放卖点**：配料、营养成分、低糖/无糖/低脂/低卡、蛋白质含量、检测报告、认证、产地、专利、销量、口碑等，都必须来自用户提供的可验证资料。
3. **把功效承诺改成场景体验**：食品饮料优先表达口感、风味、规格、便携、饮用/食用场景、包装体验、真实配料和真实营养信息。
4. **把医疗语言改成日常管理语言**：不得说治疗、预防、改善疾病；可在有依据且不误导的前提下，说“日常营养补充”“日常饮用选择”“轻负担场景”“状态管理”。
5. **不制造恐惧和刚需幻觉**：不得通过疾病后果、身体损伤、恐吓式对比推动购买，例如“不喝就会免疫差”“不补就会生病”。
6. **视觉也要合规**：画面不得出现医院、医生、白大褂、处方、药片、注射器、医疗检测场景、虚假奖章/认证、夸张前后对比等暗示医疗效果的元素。

## 2. 必须先判断的类目

生成食品、饮料、营养品视觉方案前，先将产品归入以下类别，并标注风险等级：

| 类目 | 常见产品 | 默认风险 | 核心判断 |
|---|---|---:|---|
| 普通食品 | 零食、冲调食品、代餐形态普通食品、休闲食品 | 中 | 只能围绕口味、配料、规格、场景、包装、真实营养成分表达，不得声称保健功能或疾病相关效果。 |
| 饮料 | 即饮茶、咖啡、果汁、乳饮、气泡水、植物饮 | 中 | 重点防范“降火、排毒、提神立刻见效、改善睡眠、降糖减脂”等功效化表达。 |
| 蛋白粉 | 乳清蛋白、植物蛋白、复合蛋白粉 | 中高 | 可基于营养成分表表达蛋白质含量、补充场景；不得承诺增肌、减脂、修复机能、提高免疫力。 |
| 草本饮 | 菊花茶、金银花饮、酸梅汤、草本茶饮 | 高 | 草本原料容易被误读为药用，必须避免清热解毒、降火、消炎、治嗓子疼、护肝等药品化表达。 |
| 营养补充类产品 | 维生素、矿物质、益生菌、膳食纤维、胶原蛋白等 | 高 | 必须基于真实成分和资质；不得承诺治疗、预防、改善疾病或替代正常饮食/药物。 |
| 高客单滋补类产品 | 燕窝、海参、阿胶、参类、灵芝类、虫草类等 | 高 | 重点防范“补气血、抗癌、增强免疫、抗衰、修复、医生推荐、顶级滋补”等高风险词。 |
| 保健食品 | 蓝帽子产品、注册/备案保健食品 | 很高 | 仅可在批准范围内表达，不得涉及疾病预防、治疗功能；需展示真实资质和必要提示。 |
| 特殊膳食/特殊医学用途配方食品 | 婴幼儿食品、运动营养、特医食品等 | 很高 | 必须严格依据标签、说明书和法规要求，不得扩大适用人群或替代治疗。 |

## 3. 禁止表达

以下表达不得出现在主图、广告图、直播间入口图、详情页、短视频封面、口播字幕、AI 生图提示词和设计备注中。即使用户提供，也应提示删除或改写；除非用户提供合法资质且经专业审核允许表达，也应严格限定范围。

### 3.1 疾病治疗、预防、改善类

- 治疗疾病、治愈疾病、根治、康复、疗程、处方、药效、见疗效。
- 预防疾病、防癌、防感冒、防三高、防糖尿病、防脂肪肝、防便秘、防失眠。
- 改善疾病、改善高血压、改善高血糖、改善高血脂、改善脂肪肝、改善鼻炎、改善过敏、改善炎症。
- 治疗嗓子疼、缓解咽炎、消炎、止咳、化痰、护肝、养胃治胃病、修复肠胃。
- 降血糖、降血脂、降血压、抗癌、抗病毒、抗菌杀菌、排毒、清宿便。

### 3.2 身体机能修复与保健功效类

- 修复身体机能、修复身体、修复细胞、修复肝肾、修复肠道屏障、修复胃黏膜。
- 增强免疫力、提高免疫力、提升免疫、提高抵抗力、增强抵抗力、增强体质。
- 抗衰老、逆龄、返老还童、年轻十岁、延缓衰老、延长寿命。
- 快速增肌、躺瘦、暴瘦、燃脂、刮油、阻断吸收、吃了就瘦。
- 改善睡眠、治疗失眠、安神助眠立竿见影、调节内分泌、改善焦虑抑郁。

### 3.3 立刻见效与绝对承诺类

- 立刻见效、马上见效、当天见效、一次见效、三天见效、见效快。
- 100%有效、保证有效、一定有效、人人有效、永久有效、零风险。
- 无任何副作用、绝无副作用、完全无害、绝对安全、适合所有人。
- 不满意包治好、无效退款但暗示必然效果、吃完必变好。

### 3.4 绝对化与排名类

- 全网第一、行业第一、销量第一、口碑第一、抖音第一、平台第一。
- 最强、最佳、最高级、国家级、顶级、极品、极致、天花板、唯一。
- 领导品牌、首选品牌、王牌产品、冠军产品、第一选择。
- 远超所有竞品、吊打同行、碾压同类、比药还好。

> 注：如果确有官方奖项、国家/行业标准分级、平台榜单、销量数据或商标名称包含相关词，必须提供可验证依据，并在文案中准确限定时间、范围、来源和口径；不能泛化为商品功效或品质承诺。

### 3.5 医疗、专家与药用暗示类

- 医生推荐、专家推荐、院士推荐、医院同款、临床验证、医学验证。
- 医疗级、医用级、药用效果、药食同源等同药效、处方级、药房级。
- 白大褂背书、医院场景背书、诊疗前后对比、检测报告伪背书。
- 替代药物、替代治疗、比药更安全、长期吃药不如吃它。

### 3.6 无依据背书和误导类

- 虚构认证、虚构检测报告、虚构专利、虚构产地、虚构进口身份。
- 虚构销量、虚构复购率、虚构达人/明星/专家/用户评价。
- 无依据对比竞品，贬低竞品或暗示竞品有害。
- 用“科学研究证明”“实验数据证明”“权威认证”但不提供具体来源和文件。

## 4. 高风险词替代表达

替代表达的原则：**从“结果承诺”改为“日常场景 + 产品特征 + 温和体验”**。替代表达也不能凭空添加事实；涉及成分、含量、低糖、检测、认证时仍需用户提供依据。

| 高风险表达 | 风险原因 | 更稳妥替代表达 |
|---|---|---|
| 增强免疫力 / 提高免疫力 | 保健功效或医疗化暗示 | 日常营养支持 / 关注日常营养管理 / 为日常饮食做补充 |
| 提高抵抗力 / 增强体质 | 暗示疾病预防 | 日常状态管理 / 日常营养补充选择 / 忙碌生活里的营养搭配 |
| 治疗嗓子疼 / 缓解咽炎 | 疾病治疗暗示 | 换季、熬夜、用嗓场景下的清爽饮用选择 / 清润口感 / 清爽入口 |
| 降火 / 清热解毒 | 草本药用功效暗示 | 清爽、轻负担、草本风味 / 餐后清爽饮用 / 换季清爽口感 |
| 修复身体 / 修复机能 | 身体机能修复暗示 | 日常状态管理 / 日常营养补给 / 给忙碌状态一个轻松补充 |
| 抗衰老 / 逆龄 | 功效承诺与夸大 | 状态管理 / 内在营养支持 / 轻龄感表达 / 精致生活方式表达 |
| 排毒 / 清宿便 | 医疗和虚假功效风险 | 轻盈饮食搭配 / 膳食纤维补充（需依据）/ 餐后轻负担场景 |
| 降血糖 / 控糖治疗 | 疾病治疗或预防 | 关注糖分摄入管理 / 低糖或无糖配方（需符合营养成分依据） |
| 减肥 / 暴瘦 / 燃脂 | 身材承诺和药品化 | 轻负担饮食选择 / 运动后补给 / 控制热量摄入场景（需依据） |
| 改善睡眠 / 治失眠 | 疾病或功能承诺 | 睡前放松仪式感 / 晚间温和饮用场景 / 无咖啡因饮用选择（需依据） |
| 养胃 / 治胃病 | 疾病治疗暗示 | 早餐搭配 / 温和口感 / 餐间补充选择 |
| 护肝 / 解酒 | 医疗化和夸大承诺 | 聚餐后清爽饮用 / 餐桌搭配饮品 / 清新口感 |
| 消炎 / 抗菌 / 抗病毒 | 医疗治疗暗示 | 清爽口感 / 清洁配方表述（仅限非食品场景）/ 草本风味 |
| 医生推荐 | 医疗背书风险 | 品牌推荐 / 真实用户反馈（需授权与证据）/ 口碑选择（需依据） |
| 医疗级 / 药用效果 | 药品化误导 | 严选原料（需依据）/ 标准化生产（需依据）/ 品质可追溯（需依据） |
| 立刻见效 | 效果承诺 | 即开即饮 / 入口清爽 / 方便快捷 / 适合当前场景 |
| 100%有效 | 绝对承诺 | 适合日常搭配 / 多场景可用 / 体验因人而异 |
| 全网第一 / 最强 / 顶级 | 绝对化和排名风险 | 热销款（需依据）/ 高关注款（需依据）/ 品质之选 / 经典口味 |
| 无任何副作用 | 绝对安全承诺 | 配料表清晰 / 按建议食用 / 特殊人群请查看标签或咨询专业人士 |

## 5. 不同类目的合规提醒

### 5.1 普通食品

- **可优先表达**：口味、风味、口感、规格、包装、便携、食用方法、真实配料、真实营养成分、生产信息、适用场景。
- **慎用表达**：健康、滋养、轻负担、低糖、低脂、低卡、无添加、天然、有机、儿童适用、老人适用。
- **禁用方向**：保健功能、疾病预防治疗、改善身体机能、替代正餐或替代药物、无依据功效对比。
- **视觉建议**：用餐桌、办公室、早餐、下午茶、户外补给等生活化场景承接需求，不使用医院、药盒、处方、人体器官示意图。

### 5.2 饮料

- **可优先表达**：清爽口感、风味层次、冷藏更好喝、即开即饮、聚餐/通勤/运动后/办公室场景、容量规格、糖分信息（需依据）。
- **慎用表达**：提神、醒脑、解腻、轻负担、0 糖、低卡、无咖啡因、含电解质、含膳食纤维。
- **禁用方向**：降火、清热解毒、解酒护肝、改善睡眠、治疗嗓子疼、减肥燃脂、控糖治疗。
- **视觉建议**：强化冰感、水润感、果味/茶感/草本风味和饮用场景，不用药材抓药、诊疗、疗效曲线等画面。

### 5.3 蛋白粉

- **可优先表达**：蛋白质来源、每份蛋白质含量、冲泡方式、口味、运动后/早餐/加餐场景、规格和便携性（均需依据）。
- **慎用表达**：增肌、塑形、饱腹、代餐、低脂低糖、运动营养、适合健身人群。
- **禁用方向**：快速增肌、修复肌肉损伤、治疗营养不良、提高免疫力、吃了就瘦、替代正餐且无依据。
- **视觉建议**：使用健身包、摇摇杯、早餐桌、运动后补给等场景；避免人体肌肉修复、医疗营养治疗暗示。

### 5.4 草本饮

- **可优先表达**：草本风味、清爽口感、冷热皆宜、换季饮用、熬夜/用嗓/聚餐后的清爽饮用选择。
- **慎用表达**：清润、润喉、轻负担、传统配方、草本配比、古法工艺。
- **禁用方向**：降火、清热解毒、消炎、止咳、治疗咽炎、护肝、祛湿、排毒、药用效果。
- **视觉建议**：可展示真实草本原料与饮品质感，但不要使用中药铺、药方、药碗、医生问诊、身体器官修复等暗示。

### 5.5 营养补充类产品

- **可优先表达**：真实营养成分、每份含量、适用食用场景、补充方式、口味、便携、配料表透明。
- **慎用表达**：补充日常所需、营养支持、状态管理、适合熬夜/运动/办公人群、益生菌/维生素/矿物质功能描述。
- **禁用方向**：增强免疫力、提高抵抗力、改善疾病、治疗便秘、调节肠胃疾病、抗衰老、改善睡眠、改善焦虑。
- **视觉建议**：使用“营养信息可视化 + 场景人群 + 使用方法”，不使用病症对照、疗效曲线、器官示意、医生推荐。

### 5.6 高客单滋补类产品

- **可优先表达**：原料等级或规格（需依据）、产地溯源（需依据）、工艺流程（需依据）、礼赠场景、包装质感、食用方法、品牌服务。
- **慎用表达**：滋补、养护、精致状态、内在营养、送长辈、送礼体面、日常调养。
- **禁用方向**：补气血、抗癌、提高免疫力、抗衰老、修复身体、药用效果、医生推荐、顶级滋补、包治虚弱。
- **视觉建议**：用高品质原料、溯源地图、礼盒开箱、家庭关怀场景建立信任；避免疾病恐吓、人体器官、医疗权威背书。

## 6. 主图和详情页输出要求

每次生成主图、商品卡图、广告图、直播间入口图、短视频封面和详情页时，都要逐项检查以下问题：

1. **是否有医疗化表达**：治疗、预防、改善疾病、药效、处方、医生、医院、临床、医疗级、药用效果等。
2. **是否有绝对化表达**：全网第一、最强、顶级、唯一、100% 有效、永久有效、零风险、无任何副作用等。
3. **是否有无依据对比**：对竞品、同类、药品、其他保健食品进行无来源对比，或用“远超、吊打、碾压”等贬低表达。
4. **是否有夸大承诺**：立刻见效、人人适用、吃完就变好、保证有效、快速改变身体状态等。
5. **是否有平台高风险词**：疾病词、医疗词、疗效词、绝对化排名词、虚假背书词、恐惧营销词。
6. **是否有误导消费者的表达**：普通食品暗示保健食品，营养品暗示药品，草本原料暗示中药疗效，视觉上伪造认证/检测/权威背书。
7. **是否有资料缺口**：凡涉及功能、成分、含量、认证、检测、销量、评价、适用人群、榜单排名，是否已标注“需补充依据”。
8. **是否有特殊人群风险**：儿童、孕妇、哺乳期、老人、疾病人群、过敏人群等，不得随意宣称适用；必要时提示查看标签或咨询专业人士。

## 7. 可用、慎用、禁用表达分级

| 分级 | 判断标准 | 输出处理 |
|---|---|---|
| 可用表达 | 仅描述真实可见信息、口味、规格、包装、场景、食用方法，或基于用户提供资料的客观信息。 | 可进入主图和详情页，但仍需保持准确、不过度。 |
| 慎用表达 | 可能触及健康、营养、低糖低脂、适用人群、功能体验、原料价值、榜单口碑。 | 必须要求依据；建议限定场景、范围和来源；必要时改成温和表达。 |
| 禁用表达 | 疾病治疗预防、药品化、身体机能修复、绝对承诺、虚假背书、无依据对比、恐惧营销。 | 删除，不进入任何视觉与文案输出；提供替代表达。 |
| 需补充依据 | 可表达但缺少证明材料，如检测报告、营养成分表、认证证书、榜单截图、授权评价。 | 标注“需补充依据”，不得直接作为确定卖点使用。 |

## 8. AI 生图与设计执行合规边界

- 不生成药片、胶囊、针剂、处方笺、医疗器械、医院、诊室、医生问诊等暗示药品或治疗的画面。
- 不生成“前后对比”的身体变化、疾病恢复、体型暴瘦、皮肤逆龄等功效承诺画面。
- 不生成虚假认证章、虚假检测报告、虚假奖杯、虚假媒体报道、虚假专家形象。
- 不用红十字、医疗蓝、药房货架等易混淆医疗场景的视觉符号。
- 食品饮料画面优先使用真实产品包装、真实原料、饮用/食用场景、口感质感、规格组合、礼赠开箱和品牌服务信息。
- AI 提示词中如需留白，应写“预留中文文案区域”，不要让生图模型直接生成大段功效文案。
