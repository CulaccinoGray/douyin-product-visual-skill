# 详情页视觉框架

## 目标

详情页不是资料堆砌，而是按用户决策路径逐步解决疑问：为什么适合我、为什么可信、为什么值得买、为什么现在买。

## 推荐模块顺序

1. **首屏承接**：复用主图核心卖点，确认用户没有点错。
2. **核心利益点**：用一句话讲清主要购买理由。
3. **人群与场景**：展示典型使用场景，降低代入门槛。
4. **产品差异**：解释与竞品或传统选择的差异，避免贬低式对比。
5. **成分/工艺/结构说明**：用可验证信息支撑卖点。
6. **规格与使用方式**：解决怎么用、买多少、适合什么频次。
7. **信任背书**：展示真实资质、检测、生产信息、品牌信息。
8. **购买理由收束**：用组合装、囤货、赠品或活动承接下单，但不得虚构。

## 模块写法

每个详情页模块建议包含：

- 模块目的：解决哪一个购买顾虑。
- 主视觉：画面主体、素材、背景和信息层级。
- 主标题：移动端一屏内可读。
- 辅助文案：解释依据或使用场景。
- 设计注意：字号、留白、色彩、图片比例。
- 合规注意：不能出现的词和需要证明的表述。

## 页面节奏

- 前 3 屏解决“我为什么要继续看”。
- 中段解决“它凭什么可信”。
- 后段解决“怎么买更合适”。
- 避免连续多屏纯文字，优先图文结合、图标化表达和场景化展示。

## 推荐输出格式

```markdown
### 详情页模块 {编号}：{模块名}
- 决策作用：
- 页面主标题：
- 画面建议：
- 信息层级：
- 可用素材：
- 文案方向：
- 合规注意：
```
