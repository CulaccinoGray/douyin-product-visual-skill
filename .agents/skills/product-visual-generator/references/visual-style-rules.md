# 视觉风格与执行规则

本文件用于规范抖音电商产品主图、商品卡图、广告图、直播间入口图和详情页长图的视觉风格选择与落地执行。所有视觉风格都必须服务**点击、理解、信任、转化**，不能只追求审美概念。

## 一、通用视觉原则

### 1. 成交优先

- 视觉的第一目标是让用户在 1-3 秒内知道“这是什么、为什么值得点、为什么值得买”。
- 主图优先解决点击理由，详情页优先解决购买决策链路。
- 每个视觉元素都要有转化作用：吸引停留、放大痛点、解释卖点、建立信任、降低顾虑或推动下单。
- 不要为了品牌调性牺牲商品识别度、核心卖点和移动端可读性。

### 2. 信息清晰

- 一张图只讲一个核心主题，避免同时塞入过多卖点、场景、参数和权益。
- 主标题建议控制在 8-14 个汉字；主标题不能超过两行。
- 主图信息层级建议不超过 3 层：主标题、核心卖点/场景、辅助利益点/福利。
- 关键文字与背景必须高对比，缩小到手机商品卡尺寸后仍能看清。
- 检测编号、资质说明、成分细节、规则小字不适合作为首屏主卖点，应放在详情页或辅助信息区。

### 3. 产品主体突出

- 产品主体必须清晰、完整、不变形，不得拉伸包装比例或随意修改包装信息。
- 主图中产品主体建议占画面 35%-60%，具体根据包装大小、组合装数量和文案留白调整。
- 包装文字、品牌 Logo、规格信息尽量保持可识别，避免过度虚化、遮挡或裁切核心信息。
- 多 SKU、组合装、囤货装要明确数量关系，避免让用户误解到手规格。

### 4. 场景真实

- 场景必须匹配目标用户、价格带、使用频次和真实消费环境。
- 食品饮料场景应强化口感、食欲感、清爽感和真实饮用/食用时刻。
- 家庭、办公室、户外、健身、送礼、直播间等场景要服务“我什么时候会用到”。
- 不要使用与商品价格带明显不符的过度奢华场景，也不要用无法证明的专家、医院、实验室背书误导用户。

### 5. 风格统一

- 同一套主图与详情页要统一色彩、字体、图标、光影、背景材质和信息层级。
- 主图可强刺激，详情页可更完整解释，但视觉语言不能割裂。
- 促销页、直播间入口图可以更直接，但仍需与品牌和商品包装保持识别一致。
- 统一不是每张图都相同，而是围绕同一产品心智做差异化分工。

### 6. 色彩服务品类心智

- 食品饮料：优先清爽、干净、有食欲、有口味联想的色彩，如水蓝、果绿色、奶白、橙黄、莓果红等。
- 营养品：优先可信、克制、专业、干净的色彩，如白、浅灰、浅蓝、深蓝、银色、低饱和绿色等，避免医疗化符号。
- 母婴/家庭用品：优先柔和、安全、温暖的色彩，如米白、暖黄、浅粉、浅蓝、木色等。
- 高客单产品：优先低饱和、深色、金属、皮革、玻璃、磨砂等质感表达，突出品质与价值感。
- 年轻潮流产品：可使用高饱和撞色、渐变、贴纸、霓虹、运动感元素，但不能遮挡商品和核心信息。

### 7. 不要为了高级而高级

- “高级感”必须转化为可执行设计：更好的留白、更清晰的主体、更真实的材质、更克制的信息层级、更可信的光影。
- 如果高级简约导致用户看不懂品类、卖点和到手规格，应优先恢复转化信息。
- 不要只写“高级、大气、干净、质感”，必须明确主体比例、文案位置、色彩、背景、道具、光线和移动端阅读效果。

## 二、不同视觉风格规则

### 1. 高级简约风

| 维度 | 规则 |
|---|---|
| 适合产品 | 高客单食品礼盒、精品饮品、护肤个护、数码配件、家居用品、品牌升级款、送礼型商品。 |
| 适合人群 | 重视品质、审美、品牌感和送礼体面的用户；一二线城市用户；愿意为质感和体验付费的人群。 |
| 色彩方向 | 低饱和中性色、奶白、米白、浅灰、黑金、深蓝、墨绿、香槟金；控制色彩数量，通常 1 个主色 + 1 个辅助色。 |
| 光影方向 | 柔和棚拍光、边缘轮廓光、干净高光、细腻阴影；避免廉价强闪光和杂乱反光。 |
| 场景道具 | 石材台面、亚克力、玻璃、金属托盘、丝带、礼盒、少量真实原料；道具少而精。 |
| 构图方式 | 中心构图、左右留白、三分法、产品大主体 + 少量卖点；详情页可使用大留白、局部特写、材质细节。 |
| 不适合的表达 | 不适合低价强促销、秒杀囤货、卖点复杂且需要大字解释的商品；避免过度留白导致用户看不懂利益点。 |

### 2. 清爽夏日风

| 维度 | 规则 |
|---|---|
| 适合产品 | 饮料、果汁、茶饮、气泡水、冰品、酸奶、轻食、洗护、清凉感个护、夏季户外用品。 |
| 适合人群 | 追求清爽、低负担、解腻、补水、户外休闲和夏季消费场景的年轻及家庭用户。 |
| 色彩方向 | 水蓝、薄荷绿、柠檬黄、白色、透明感浅色、果味色；整体明亮通透。 |
| 光影方向 | 明亮自然光、水面反光、冰块折射、清透高光、轻微逆光；突出冰凉、清新、轻盈。 |
| 场景道具 | 冰块、水珠、玻璃杯、果片、薄荷叶、户外野餐布、泳池、水面、冷藏柜；原料必须与真实配料相符。 |
| 构图方式 | 产品前景大主体，背景水波或户外虚化；可用飞溅水花、冰块环绕、斜向动线制造清爽点击感。 |
| 不适合的表达 | 不适合厚重暗色、油腻高饱和背景、过多金属科技元素；食品饮料不得暗示治疗、减肥或特殊功效。 |

### 3. 家庭场景风

| 维度 | 规则 |
|---|---|
| 适合产品 | 家庭囤货食品、早餐饮品、儿童零食、厨房用品、家清、个护、母婴、宠物、日用消耗品。 |
| 适合人群 | 家庭采购者、宝妈宝爸、注重安全和性价比的用户、多人使用或高频消耗场景用户。 |
| 色彩方向 | 暖白、奶油色、木色、浅黄、浅蓝、柔和绿色；整体温暖、干净、可信。 |
| 光影方向 | 居家自然光、柔和窗光、温暖环境光；避免过暗、过冷或影楼感过强。 |
| 场景道具 | 餐桌、厨房台面、冰箱、收纳柜、儿童餐具、家庭早餐、亲子互动、家庭囤货陈列；人物使用需真实自然。 |
| 构图方式 | 产品 + 使用场景组合，突出“家里常备”“全家可用”“早餐/晚餐/清洁时刻”；详情页可用场景分屏解释不同家庭成员需求。 |
| 不适合的表达 | 避免过度豪宅化、样板房化、人物摆拍僵硬；涉及儿童、孕产、健康类表达必须谨慎，不能夸大安全或功效。 |

### 4. 专业科技风

| 维度 | 规则 |
|---|---|
| 适合产品 | 数码电器、智能家居、功能型个护、运动装备、营养品、配方型饮品、需要解释结构/参数/工艺的商品。 |
| 适合人群 | 理性决策、关注参数、成分、工艺、效率和专业感的用户；男性用户、职场用户、运动健身人群。 |
| 色彩方向 | 白、银、浅灰、深蓝、科技蓝、黑、荧光蓝点缀；控制饱和度，突出理性和可信。 |
| 光影方向 | 冷色棚拍光、轮廓光、金属高光、局部发光线条；保持干净克制，避免医疗化。 |
| 场景道具 | 参数卡片、结构剖面、网格背景、光线轨迹、实验级干净台面、运动或办公场景；资质和数据必须真实可证。 |
| 构图方式 | 产品中心或右侧大主体，左侧信息模块解释参数；详情页适合用分层图、图标、流程图、对比表说明机制。 |
| 不适合的表达 | 食品、饮料、营养品不得使用医院、白大褂、药丸、治疗场景；不得虚构检测报告、专家背书或无法证明的数据。 |

|---|---|
| 适合产品 | 茶饮、草本饮品、传统风味食品、滋补类普通食品、香氛、洗护、礼盒、地域特色农产品。 |

| 色彩方向 | 米白、宣纸色、竹青、茶褐、陶土色、墨绿、浅金；整体自然、温润、克制。 |

### 6. 年轻潮流风

| 维度 | 规则 |
|---|---|
| 适合产品 | 新式饮品、零食、潮玩、运动用品、美妆个护、服饰配件、联名款、校园/职场年轻用户商品。 |

| 场景道具 | 贴纸、手写涂鸦、潮流图形、运动场、街头、办公桌、校园、派对元素、社交媒体卡片。 |

| 不适合的表达 | 不适合严肃高客单、专业医疗感、成熟送礼型商品；避免过多装饰压住产品和点击理由。 |

### 7. 直播间强转化风

| 维度 | 规则 |
|---|---|
| 适合产品 | 直播间引流图、直播贴片、秒杀福利图、组合装、囤货装、价格敏感型商品、爆品承接图。 |
| 适合人群 | 价格敏感、即时决策、被福利和稀缺感驱动、需要快速知道“现在买有什么好处”的用户。 |
| 色彩方向 | 红、橙、黄、黑金、高对比白字；促销氛围强，但要避免低俗和杂乱。 |
| 光影方向 | 高亮度、高对比、强聚焦、舞台光或直播间灯光；产品和价格/福利信息必须最醒目。 |
| 场景道具 | 直播间背景、货架、主播手持、福利标签、倒计时模块、组合装堆头、礼品/赠品展示；价格和权益必须真实。 |
| 构图方式 | 产品大主体 + 大标题 + 强福利模块；常用左右分区、上中下三段式、爆炸贴/角标；移动端优先大字。 |
| 不适合的表达 | 不适合含蓄留白、过度品牌大片、文艺小字；不得虚构限时、最低价、销量、赠品和平台背书。 |

## 三、AI 生图提示词规则

AI 生图提示词用于生成可被设计二次加工的视觉素材，不用于生成不可核验的证据、文字承诺或资质背书。提示词应尽量让 AI 生成画面结构和氛围，中文卖点、价格、资质编号等关键信息应由设计师后期排版。

### 1. 提示词必备字段

每个提示词建议按以下字段组织：

```markdown
- 产品主体：{产品包装/瓶身/盒装/组合装}，{数量}，{摆放角度}，{占画面比例}，包装清晰不变形
- 场景：{厨房/办公室/户外/直播间/餐桌/纯色棚拍/货架等}
- 构图：{中心构图/左右分区/上下分层/三分法/斜向动线/前景原料+背景虚化}
- 镜头角度：{平视/45 度俯拍/低角度仰拍/微距特写/正面棚拍}
- 光线：{明亮自然光/柔和棚拍光/高对比商业光/清透逆光/暖色窗光}
- 背景：{纯色渐变/真实厨房/水面/木桌/科技网格/直播间货架/宣纸纹理}
- 色彩：{主色+辅助色}，符合品类心智和品牌包装
- 材质：{玻璃/金属/纸盒/塑料瓶/木质/石材/冰块/水珠/陶瓷等}
- 情绪氛围：{清爽/可信/温暖/专业/年轻/高端/强促销}
- 负面提示词：错误文字、乱码、产品变形、包装信息错误、假 Logo、虚假认证、医疗暗示、医院、白大褂、药丸、夸张功效、竞品贬低、低清晰度、脏乱背景、手指畸形、人物脸部崩坏
```

### 2. 提示词写作原则

- 先写产品主体，再写场景和构图，确保 AI 不把背景做得比商品更抢眼。
- 明确“文案留白区域”，不要要求 AI 直接生成大量中文小字。
- 食品饮料提示词要加入真实可见的食欲感/清爽感元素，如水珠、冰块、果片、热气、酥脆断面、餐桌光影等，但原料必须与真实配料一致。
- 高客单产品要强调材质、边缘光、细腻阴影、干净留白和高级背景，不要堆满促销贴纸。
- 直播间图要更直接：大主体、大福利区、高对比背景、明确直播场景和强引导留白。
- 广告图要更聚焦点击理由：痛点场景、核心利益点、强对比画面或明确使用场景，不要把所有卖点都放进一张图。

### 3. 风格化提示词模板

#### 高级简约风提示词

```markdown
产品主体：{产品名称/包装形态} 正面清晰展示，占画面 45%，包装不变形；场景：高级棚拍静物台面；构图：中心构图，右侧或上方预留主标题区域；镜头角度：平视略微俯拍；光线：柔和商业棚拍光，细腻轮廓光；背景：米白/浅灰纯色渐变背景，少量石材或亚克力台面；色彩：低饱和中性色，少量品牌主色点缀；材质：纸盒/玻璃/金属质感真实，干净反光；情绪氛围：克制、高端、可信、送礼体面；负面提示词：错误文字、乱码、产品变形、包装信息错误、假 Logo、虚假认证、夸张促销贴纸、杂乱背景、低清晰度。
```

#### 清爽夏日风提示词

```markdown
产品主体：{产品名称/瓶装/罐装/杯装} 清晰展示，占画面 45%-55%，表面有自然水珠；场景：夏日冷饮场景；构图：产品居中偏右，前景冰块和真实原料点缀，左侧预留文案；镜头角度：45 度平视；光线：明亮自然光，清透逆光，水面反光；背景：浅蓝水面或户外虚化背景；色彩：水蓝、薄荷绿、白色、果味色；材质：玻璃、冰块、水珠、果片质感真实；情绪氛围：清爽、冰凉、轻盈、有食欲；负面提示词：错误文字、乱码、产品变形、虚假原料、医疗暗示、减肥暗示、脏乱背景、过暗光线、低清晰度。
```

#### 家庭场景风提示词

```markdown
产品主体：{产品名称/组合装/家庭装} 清晰摆放，占画面 40%-50%；场景：真实家庭厨房或餐桌；构图：产品在前景，家庭使用场景在中后景虚化，右上方预留标题；镜头角度：平视或轻微俯拍；光线：温暖自然窗光，柔和阴影；背景：干净厨房、木质餐桌、冰箱或收纳柜；色彩：暖白、奶油色、木色、浅黄；材质：包装、餐具、木桌、布艺真实自然；情绪氛围：安心、日常、温暖、适合家庭囤货；负面提示词：错误文字、乱码、产品变形、豪宅过度奢华、人物僵硬、儿童夸张功效暗示、虚假安全承诺、杂乱背景。
```

## 四、设计执行规则

### 1. 字要大

- 商品卡和直播间入口图必须优先考虑手机小图阅读，主标题必须足够大。
- 主标题建议占画面宽度 45%-70%，具体根据产品主体和留白调整。
- 辅助卖点、规格、价格、福利信息要分层，不要全部使用同等字号。
- 字体建议选择粗黑体、圆体或品牌统一字体；避免过细、过花、难读的字体。

### 2. 主标题不能超过两行

- 主标题只表达一个核心点击理由，如口味、场景、利益点、规格或福利。
- 超过两行会降低商品卡识别效率，应拆分为主标题 + 辅助卖点。
- 详情页标题也要短句化，每屏先让用户知道这一屏解决什么问题。

### 3. 产品不要变形

- 不得拉伸、压缩、镜像导致包装比例异常。
- 不得随意修改包装上的品牌、口味、规格、条码、生产信息等真实内容。
- AI 生图生成的包装文字容易错误，正式投放前必须用真实产品图或设计源文件替换。
- 组合装和赠品图要真实对应到手信息，避免误导消费者。

### 4. 食品饮料要突出食欲感/清爽感

- 食欲感可通过真实原料、切面、热气、酥脆感、浓稠感、餐具和食用场景呈现。
- 清爽感可通过冰块、水珠、玻璃杯、透明液体、水面、浅色背景和明亮光线呈现。
- 原料、口味、营养成分必须基于真实资料，不得为了画面好看添加不存在的原料。
- 不要用药品、胶囊、医院、白大褂等元素包装普通食品或饮料。

### 5. 高客单产品要有质感

- 高客单商品要减少廉价贴纸和过多促销口号，优先表现材质、工艺、包装、礼赠价值和细节。
- 可使用石材、金属、玻璃、皮革、丝带、礼盒、深色背景、轮廓光和局部特写增强价值感。
- 价格和权益仍需清晰，但应通过有秩序的版式呈现，而不是堆满爆炸贴。

### 6. 直播间图要更直接

- 直播间入口图要让用户立刻知道：卖什么、有什么福利、为什么现在进。
- 优先使用大产品、大标题、大福利、大按钮感引导。
- 福利、价格、赠品、倒计时、库存、销量等必须真实可证；没有依据时只能用“直播间福利”“进直播间看活动”等稳妥表达。
- 直播间图不适合含蓄文艺表达，也不适合把核心利益点藏在小字里。

### 7. 广告图要更聚焦点击理由

- 广告图只抓一个最强点击理由：痛点、场景、口味、颜值、价格、规格、信任或新奇感。
- 画面要有强对比或强代入：使用前后场景、通勤/办公室/家庭/户外时刻、问题与解决方案分区等。
- 信息流广告要避免像详情页截图一样塞满小字；应先让用户愿意停留，再承接到商品页解释。
- 如果需要投放多张广告图，应按不同人群和不同点击理由拆分，不要只替换背景颜色。

## 五、审核检查清单

- 是否一眼能看出商品是什么、适合谁、为什么值得点？
- 产品主体是否清晰、完整、不变形、规格关系不误导？
- 主标题是否足够大，且不超过两行？
- 色彩是否符合品类心智、品牌包装和目标人群？
- 场景是否真实可信，是否匹配价格带和使用场景？
- 食品、饮料、营养品是否避免医疗化、功效夸大、虚假原料和绝对化表达？
- 资质、检测、销量、价格、赠品、限时、专利、认证等是否有真实依据？
- AI 生成图是否需要替换真实包装、修正文字、删除违规元素？
- 详情页是否按购买决策链路展开，而不是简单罗列卖点？
- 直播间图和广告图是否分别解决“现在进/现在买”和“为什么点击”的问题？
